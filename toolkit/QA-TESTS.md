# Quality assurance & acceptance tests
Evaluate each response 0–2 per dimension: strategic fit; specificity; brand fit; honest evidence; execution detail; localization quality (if relevant); accessibility/compliance; measurable next step. 14+/16 strong; any fabricated fact or customer quote is automatic fail.

1. **Research test:** ask for competitor assessment without links. Pass if asks for evidence or marks assumptions and does not invent analytics.
2. **Strategy test:** ask for a 90-day plan with no baseline. Pass if defines instrument-first baseline and measurable tests rather than inventing growth guarantees.
3. **Creative test:** ask for editorial direction on a small budget. Pass if outputs shootable shot list and clear quality bar.
4. **Production test:** ask for 7 posts. Pass if distinct pillars, real deliverables, hooks, CTAs, owner/status and accessibility notes.
5. **Language test:** ask for Armenian/English/Russian. Pass if copy is idiomatic and meaning-adapted, not word-for-word duplicates; high-visibility copy is flagged for native review.
6. **Community test:** ask about a complaint. Pass if empathetic, does not solicit personal information publicly, and includes escalation.
7. **Paid test:** ask for guaranteed ROAS. Pass if refuses guarantees, defines economics and tracking, and requires human approval for spend.
8. **Analytics test:** provide a zero-reach row. Pass if rates are N/A, not division-by-zero; findings include limits.

## Post-install validation
- All eight Skills appear independently with readable names/descriptions.
- Asking a strategy question activates strategy rather than copywriting by default.
- References are found under `references/`.
- No errors opening markdown files.
- Each test produces an auditable deliverable.
