# Measurement dictionary
Define every metric by source, period, denominator, exclusions, and paid/organic status.
Reach = unique accounts reached as reported by platform (platform definitions may vary).
ER by reach = engagements / reach x 100, where engagements must be enumerated (likes, comments, saves, shares etc.).
Save rate = saves / reach x 100; share rate = shares / reach x 100.
CTR = clicks / impressions x 100 (specify link clicks vs all clicks).
Lead CVR = qualified leads / relevant landing sessions x 100 (track qualification definition).
CPA = spend / attributed acquisitions; ROAS = attributed revenue / ad spend; distinguish modeled/platform-attributed values from incremental impact.
Report row: metric | current period | comparable prior | absolute change | relative change | target or baseline | notes.
If denominator is 0 or unavailable, write N/A. Check attribution windows, organic/paid mixing, platform shifts, seasonality, small n and missing data before interpretation.
