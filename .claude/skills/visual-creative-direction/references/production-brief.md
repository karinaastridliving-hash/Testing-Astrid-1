# Production brief template
Project / campaign / version / approver / due date
Commercial objective / single-minded proposition / audience insight / desired action
Asset inventory: platform | placement | aspect ratio | approximate duration | locale | deadline | owner.
Creative concept: title; opening frame; tension; emotional payoff; key product proof; closing action.
Frames: timestamp estimate | image/shot | on-screen copy | narration | motion/edit note | required asset.
Shoot plan: location | lighting | props | talent | permissions | wardrobe | audio | setup time | priority.
Design: typographic hierarchy; color roles; caption placement; readable contrast; cover image; safe zones verified with latest platform guidance.
Approval: brand / factual claims / legal / accessibility / technical export / caption and localization.
Do not pretend image generation or software exporting occurred unless a tool was actually used.
